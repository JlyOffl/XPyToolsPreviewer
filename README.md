# XPyToolsPreviewer

Listening page for XPyTools Space links, published with GitHub Pages.

XPyTools posts each live Space to Discord with a 📋 Copy to Clipboard link that opens this page:

```
https://jlyoffl.github.io/XPyToolsPreviewer/?s=<stream>&t=<title>&h=<host>&a=<picture>&id=<space id>
```

It plays the Space as audio, shows the title and host picture on the lock screen and in Control Center, and has Copy stream link and Open in X buttons.

Static page, no secrets: everything it shows comes from the link. The source of truth is `public/listen.html` in XPyTools-Netlify; copy it here when it changes.
